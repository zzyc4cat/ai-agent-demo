如何重新安装机箱LED灯条

---

关于 Bambu Lab X1 系列 3D 打印机的机箱LED灯条的问题已经引起我们的注意。 一般情况下，LED灯条损坏的概率很小。本文将指引你如何更换LED灯条。

为了便于拆卸和更换，机箱LED灯条通过 3 个卡扣固定在横梁上。我们发现LED灯条在运输过程中松动的可能性是非常低的，所以不必担心LED灯条在使用过程中出现松动问题。

![](https://wiki.bambulab.com/x1/troubleshooting/chamer-led/loose_chamber_led.jpg)

我们的产线今后都会增加一步点胶作业来改善这种情况。但如果你收到了早期批次的产品，开箱后发现LED灯条松动，只需重新安装即可。

## 重新安装LED灯条的步骤

### 1. 关闭打印机，将工具头移到一边。

![](https://wiki.bambulab.com/x1/troubleshooting/chamer-led/move_the_toolhead.jpg)

### 2. 确认卡扣和槽口位置

确认LED灯条支架底部的 3 个卡扣，以及横梁上的 3 个槽口，如下图所示。

![](https://wiki.bambulab.com/x1/troubleshooting/chamer-led/buckles.jpg)

### 3. 安装LED灯条

对齐卡扣和槽口，将LED灯条安装到横梁上。

![](https://wiki.bambulab.com/x1/troubleshooting/chamer-led/install_led.jpg)

### 4. 将LED灯条推到对应位置

按照下图中箭头所示的方向将LED灯条推到对应位置。

![](https://wiki.bambulab.com/x1/troubleshooting/chamer-led/push_to_fix.jpg)

### 5.恭喜你，完成安装啦！

现在你已经完成了LED灯条的安装。
