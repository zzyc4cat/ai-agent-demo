## 清理料管中断裂或堵塞的耗材

非常干燥或老旧的耗材会变得非常脆。在 AMS 中使用脆性耗材会产生一系列问题。此页面适用于耗材在 PTFE 进料管内需要清除的情况。由于挤出机和 AMS 通道之间有许多不同的 PTFE 进料管，下面的视频描述了如何移除这些料管，以及如何更换它们。

注意：如果断裂的耗材丝不容易取出，卡在 PTFE 管内，你可以在一端插入一段新的较长的料线，把断裂的料线从另一端推出来。
