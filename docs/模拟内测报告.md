# 模拟内测报告

- 日期：2026-10-28
- 性质：**角色模拟**，由 AI 扮演 10 个使用者，不代表真实用户留存或付费意愿
- 方式：10 个角色 × 10 条问法，全部走真实 `/kb/ask` 接口
- 数据：`eval/beta_sim/results.jsonl`
- 账号：`beta_sim`，会话 `sim-01` ～ `sim-10`（每角色一个）

## 1. 为什么要模拟

目标用户是 X1 系列使用者，随机找人既没有设备也不知道问什么。模拟解决的是“**不同角色能不能问出真实问题、系统答得怎么样**”，不能替代真实用户验证。

## 4. 失败与问题

### 4.1 错误（1 条）

**P06「序列号在哪？」**

- 回答把“序列号”理解成 HMS 代码结构，讲了 0300 各段含义。
- 问题：口语中的“序列号”指设备 SN，与 HMS 代码无关；检索被“代码/编号”带偏。
- 影响：二手买家场景会直接问错答案。
- **已修复（2026-10-28）**：提示词增加规则 7，明确区分“序列号 / SN / 机身码”与 HMS 错误码；4 种问法（序列号在哪 / 设备序列号在哪里看 / SN 码在机身哪里 / 序列号是多少）实测均正确拒答，100 条评测指标不变（67/67、0/67、33/33）。

### 4.2 部分正确（2 条）

| 问题 | 表现 | 原因 |
|---|---|---|
| P04「废料怎么处理？」 | 答成“拆除废料槽 / 安装废料滑梯” | 问题歧义（回收 vs 废料槽），检索选了后者 |
| P08「型号差异在哪查？」 | 只答了 AMS 主板版本区分 | 问题过宽，检索命中单一文档 |

建议：对“怎么处理 / 在哪查”这类宽问题，回答先澄清范围，或列出多个可能再让用户选。

### 4.3 拒答表现（好）

库外题全部正确拒答，包括：

- 保修期、退款、发票、包装尺寸、噪音、重量
- A1 mini 屏幕更换、Prusa 校准、2024 固件号
- 第三方耗材、AMS 色数、保养周期、喷头寿命

拒答均给出“参考资料未提及”的依据，没有硬编。

## 5. 表现好的地方

1. **型号参数准确**：X1 110℃、P1 100℃、A1 mini 80℃，对比题一次答对。
2. **HMS 代码**：0300 对应 MC 运动控制，0003 热床过温等，引用到具体文档。
3. **操作步骤**：切刀卡住、屏幕黑屏、AMS 上电、固件升级失败，步骤完整且带引用。
4. **口语化问法**：“热床最高能到多少度”“喷嘴堵了怎么清理”都能命中。

## 6. 对产品的启示

| 优先级 | 事项 | 理由 |

| P0 | 序列号类问题修复（同义词 + 拒答） | 唯一硬错误，二手场景高频 |
| P1 | 宽问题澄清策略 | 2 条部分正确都源于问题歧义 |
| P1 | 延迟排查 | 5.2s 均值对内测体验偏慢 |
| P2 | 角色化欢迎语/示例问题 | 新手不知道该问什么，可在空状态给 3 个示例 |

## 7. 局限

- 问题由 AI 编写，与语料同源，存在过拟合。
- 评分含人工复核，但仍是单评审。
- 只测 API，没有测真实 UI 操作路径。
- **不能替代真实用户**：留存、付费、真实工作流仍需 3–5 名 X1 用户验证。
