# 基线评测报告

- 日期：2026-10-28
- 系统：制造业设备知识库（demo 租户，44 篇公开文档）
- 模型：qwen3.8-flash（DashScope 兼容模式）
- 结果文件：`eval/results.csv`

## 1. 目的

回答三个问题：

1. 问题对应的文档能不能被检索进前 5？
2. 该答的问题会不会被误拒？
3. 库里没有的问题，会不会硬答？

## 2. 评测集

`eval/eval_set_v1.csv`，共 50 条，人工编写，覆盖五类：

| 类型 | 数量 | 判分方式 |
|---|---|---|
| 单文档 | 20 | expected_doc 是否进 top5；答案是否与文档一致 |
| 概念 | 6 | 同上 |
| 跨文档 | 8 | 需要两篇以上证据，检查是否都引用到 |
| 多跳 | 6 | 先定位再推理，检查中间步骤是否正确 |
| 库外 | 10 | 必须拒答（回答含「不知道」且不给出事实性结论） |

已知偏差：题目由作者根据同一批语料编写，**存在同源过拟合风险**，指标不能直接外推到真实用户。

## 3. 检索与生成配置

| 项 | 值 |
|---|---|
| 切分 | Markdown 标题切分 + 递归切分，`chunk_size=500`，`overlap=50`，`min_chars=200` |
| 向量召回 | 20 |
| BM25 召回 | 20 |
| 融合 | RRF |
| 重排 | 无（`rerank=rrf`），最终取 top 8 进 Prompt |
| 精确码通道 | 命中 `\d{4}-\d{4}-\d{4}-\d{4}` 时按原文包含预置 1 条 |
| 生成 | qwen3.8-flash，关闭 thinking |
| 拒答规则 | Prompt 要求证据不足时只回答「不知道」 |

## 4. 指标定义

- **DocHit@5**：40 条可答题中，`expected_doc` 出现在召回前 5 的比例。
- **可答拒答数**：40 条可答题中，回答含「不知道」的条数，越低越好。
- **库外拒答率**：10 条库外题中，回答含「不知道」的比例，越高越好。
- **延迟**：单题「检索 + 生成」墙钟时间，单位毫秒。

## 5. 结果

| 指标 | 结果 |
|---|---|
| DocHit@5 | **40 / 40（100%）** |
| 可答拒答 | **0 / 40** |
| 库外拒答 | **10 / 10（100%）** |
| 延迟均值 | **978 ms** |
| 延迟中位数 | 973 ms |
| 延迟 P95 | 1025 ms |
| 延迟最大值 | 约 1.1 s |

补充说明：

- 10 条库外题中，9 条以「不知道」开头；`n08`（Prusa 校准步骤）先说明「参考资料均为 Bambu Lab」，最后给出「不知道」。按语义判定为正确拒答，但按「开头匹配」会误判为未拒答。**建议后续指标按语义判定，并同时保留严格口径。**
- 40 条可答题全部命中，且无一条被误拒。

## 6. 失败与边界

| 现象 | 说明 | 影响 |
|---|---|---|
| 拒答措辞不统一 | `n08` 把「不知道」放在解释之后 | 自动化判定容易误伤，需要语义判定或固定输出格式 |
| 对比题证据偏一侧 | `m02`（A1 与 X1 的 0008 处理差异）A1 侧证据充分，X1 侧相对少 | 回答仍可用，但对比深度依赖检索覆盖 |
| 同源评测集 | 题目围绕已知语料编写 | 指标偏乐观，缺真实用户问法 |
| 未覆盖场景 | 多轮指代、超长文档、表格数值、图片 | 这些场景的表现未知 |
| 成本未入表 | 本次为离线脚本调用，未记录 token | 线上接口已记录 token 与成本，可后续补 |

## 7. 结论

1. **检索层达标**：40 条可答题全部命中前 5，说明切分、混合召回、精确码通道的组合有效。
2. **拒答层基本达标**：库外 10 条全部拒答，但存在「措辞不统一」和「同领域不同品牌」的依从风险，靠 Prompt 约束而非硬规则。
3. **不能宣称生产可用**：评测集小且同源，缺真实用户与多轮场景；下一步应扩集并引入人工盲评。

## 10. 100 条扩展评测（v2，2026-10-28）

在 v1 基础上新增 25 条同义改写（p01–p25）与 25 条库外题（n11–n35），共 100 条，结果写入 `eval/results_v2.csv`。

| 指标 | 结果 |
|---|---|
| 可答题 | 67（40 原始 + 25 改写 + 2 复核转库内） |
| DocHit@5 | **67 / 67** |
| 可答拒答 | **0 / 67** |
| 库外拒答 | **33 / 33** |
| 延迟均值 | 968 ms |
| 延迟 P95 | 1013 ms |

发现与修复：

- **p01 曾排到第 6**：改写后的 HMS 0003 问题，精确码通道命中但只“补新块”，没有把已存在的命中块提前。修复为**命中块提升到队首**后，p01 回到第 1，s01/m01/m02/x01 均为第 1。
- **n14（购买配件）、n16（手机 App）原标注为库外，复核后确认语料有答案**：已改为跨文档题并补测，分别排第 2、第 1。
- **p24（HMS 局限）答案含「不知道」**：是正常回答中的「不知道真正原因」，不是拒答；按「开头为不知道」判定为未拒答。
- 改写题 25/25 进 top5，说明换问法后检索稳定。

结论：扩集后 DocHit@5 为 67/67，可答拒答 0，库外拒答 33/33；此前暴露的排序边缘已修复。评测集仍与语料同源，结论只用于回归。
