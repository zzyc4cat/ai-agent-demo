X轴阻力异常及处理方案

---


## 问题现象:

1 .打印模型有变形，如圆形的模型打印出来变成了椭圆；

2. 关机状态下，手动移动工具头，有明显难移动或移动过程中阻力不均匀的情况；

3. 可以明显看到或感觉到碳杆上有附着物或带有粘性；

![](https://wiki.bambulab.com/x1/troubleshooting/xy-abnormal-resistance/snipaste_2022-10-12_15-54-34.jpg)

4. 无撞击状态下的打印丢步或工具头异常抖动。

## 原因及解决方案

X轴阻力异常原因如下：

1. 长期打印挥发性强的材料（如ABS），会在碳杆上附着较多的粉尘或带有粘性，导致阻力异常；
2. 在工具头持续运动过程中，粉尘或碎屑卡入工具头铜套中，导致阻力异常。

解决方案：

使用异丙醇或无水酒精对碳杆进行清洁，并通过工具头移动使用清洁更全面和彻底。

## 安全和操作提示

因需要手动移动工具头和喷洒清洁剂，需要提前断开电源。

## 所需的工具

- 异丙醇（或无水酒精）
- 无尘布

![](https://wiki.bambulab.com/x1/troubleshooting/xy-abnormal-resistance/snipaste_2022-10-12_11-44-50.jpg)

## 操作指引

### 步骤1 - 关闭打印机

关闭打印机，断开电源线连接，移除玻璃上盖，将工具头移动到边上，尽可能多地露出碳杆。

![](https://wiki.bambulab.com/x1/troubleshooting/xy-abnormal-resistance/set_aside_the_toolhead.jpg)

### 步骤2 - 涂布清洁剂

将异丙醇（或无水酒精）喷洒到两根碳杆上，使整根碳杆看起来是湿润的。也可以直接用无尘布蘸取清洁剂后涂布到碳杆上。

![](https://wiki.bambulab.com/x1/troubleshooting/xy-abnormal-resistance/apply_the_clean_detergent.jpg)

### 步骤3 - 往返移动工具头

手动移动工具头，使工具头来回动作3~5次

![](https://wiki.bambulab.com/x1/troubleshooting/xy-abnormal-resistance/move_the_toolhead.jpg)

### 步骤4 - 清洁碳杆

用无尘布清洁碳杆表面。

![](https://wiki.bambulab.com/x1/troubleshooting/xy-abnormal-resistance/clean_the_rods.jpg)

### 步骤5 - 重复步骤3和步骤4

重复操作步骤3和步骤4三次或更多，直至确认手动移动工具头较处理前有明显的改善。
